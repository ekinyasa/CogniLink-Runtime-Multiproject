## Implementation Summary (Prompt 57)

### New file: `functions/r/[alias]/[link].js`

Server-side redirect endpoint with click telemetry. Pure HTTP 302 — no JS required.

#### 1) Routing grammar
```
GET /r/<alias>/<link-id>

alias   : [a-z0-9-]{1,48}  — experiment / route alias (same as public route grammar)
link-id : [a-z0-9-]{1,48}  — link id from resolved link list
```
Cloudflare Pages injects path segments via `context.params.alias` and `context.params.link`.

#### 2) Cookie model
```
Name  : exp_<alias>
Value : variant slug  (e.g. "igbio-test")
Scope : Path=/; Max-Age=2592000; SameSite=Lax; Secure
Use   : read-only attribution in /r handler; never written here
```
Cookie is written by `experiment-router.js` on first page load (RUNNING / PAUSED state). Absent cookie → redirect proceeds without experiment attribution.

#### 3) Redirect flow (8 steps)
1. **Validate** alias + link-id format → 302 FALLBACK on fail
2. **Resolve canonical slug** — Workers Cache (`routeCacheGet`) → `ROUTE_TABLE.get("route:<alias>")` on miss → `routeCacheSet` to warm
   - Bypass `resolveAlias()` intentionally: avoids double-counting `ALIAS_CLICK` + `ROUTE_RESOLVED` ops events
3. **Load hub config** — in-memory TTL cache (`loadHubConfig`) → HUB_CONFIG / LINKHUB_SLUGS KV on miss
4. **Resolve link list** — `resolveLinks(hubConfig, null)` (no global LINKHUB_CONFIG; per-slug overrides applied)
5. **Find link by id** — `links.find(l => l.id === linkId)` → 302 `/<alias>` if not found
6. **Read experiment cookie** — `readCookie(request, "exp_" + alias)` → variant or null
7. **Build UTM-annotated URL** — `buildRedirectHref()` (server-side mirror of hub JS `buildHref()`)
8. **Telemetry** via `context.waitUntil()` → 302 to target URL

UTM priority in `buildRedirectHref()`:
- `utm_content`   ← link's `utmContent` field (always)
- `utm_campaign`  ← `hubConfig.campaign` (always wins)
- `utm_experiment` ← `alias` (only if variant cookie present)
- `utm_variant`   ← cookie value (only if variant cookie present)
- `utm_source`    ← `hubConfig.defaults.utm_source`
- `utm_medium`    ← `hubConfig.defaults.utm_medium`

Canonical cleanup: existing `utm_*` on destination href stripped before applying ours (same rule as hub JS). Exception: pre-existing `utm_source` preserved.

#### 4) Telemetry payload
Fires only when variant cookie is present. Both deferred via `context.waitUntil()`.

**KV counter** (in `ALIAS_REGISTRY`):
```
key: telemetry:exp:<alias>:<variant>:click
val: incremented integer (read-modify-write, approximate)
```

**Analytics Engine event** (in `TELEMETRY_EVENTS` dataset `linkhub_telemetry_events`):
```js
writeDataPoint({
  blobs:   [alias, variant, "click", linkId],  // [0]=exp [1]=variant [2]=event [3]=link-id
  doubles: [Date.now()],                        // unix ms timestamp
  indexes: ["<alias>:<variant>"],               // fast GROUP BY filter
})
```

#### 5) Failure behaviour
| Condition | Response |
|---|---|
| Invalid alias or link-id format | 302 `/ig` |
| Alias not found in ROUTE_TABLE | 302 `/ig` |
| ROUTE_TABLE binding absent | 302 `/ig` |
| KV read error | 302 `/ig` |
| Link-id not in resolved list | 302 `/<alias>` (send user to hub) |
| KV / AE telemetry error | Silently swallowed; redirect unaffected |
| Variant cookie absent | Redirect proceeds; telemetry skipped |

Never returns 4xx/5xx — redirect endpoints must always take the user somewhere.
