

# Prompt 59 — Redirect Router Refactor

We are replacing the nested Pages Functions routing with a deterministic catch-all router and renaming the redirect namespace.

## Goal

Move the redirect engine to:

/campaign/:alias/:link

and implement it with a single catch-all Pages Function.

This avoids Cloudflare Pages dynamic routing edge cases and simplifies the router logic.

---

# 1 Remove old router structure

Delete the previous nested routing:

functions/r/[alias]/[link].js

Delete the temporary debug file:

functions/r/test.js

Remove the entire `/functions/r` directory if empty.

---

# 2 Create new catch-all router

Create:

functions/campaign/[[path]].js

Cloudflare Pages will route:

/campaign/*

to this function.

---

# 3 Router behavior

The router must:

1. Parse the path after `/campaign`
2. Extract the following values:

alias
link

Example:

/campaign/spring-2026-youtube/official

alias = spring-2026-youtube
link = official

---

# 4 Temporary behavior

For now we only test routing.

Return:

302 redirect → /ig

Implementation example:

```javascript
export async function onRequest(context) {

  const url = new URL(context.request.url)

  const parts = url.pathname
    .split("/")
    .filter(Boolean)

  const alias = parts[1]
  const link  = parts[2]

  if (!alias || !link) {
    return new Response("invalid redirect", { status: 400 })
  }

  return Response.redirect("/ig", 302)
}
```

## Implementation Summary (Prompt 59)

### Deleted files
- `functions/r/[alias]/[link].js` — old nested dynamic router (P57)
- `functions/r/test.js` — temporary debug file
- `functions/r/` — directory removed entirely (also had `.DS_Store`)
- `functions/campaign/[campaign].js` — stale single-bracket 404 stub (from P23)

### New file: `functions/campaign/[[path]].js`

Double-bracket catch-all handles all `/campaign/*` routes in a single Pages Function file. Avoids Cloudflare Pages nested dynamic routing edge cases that caused P57's `/r/[alias]/[link].js` to not execute.

**Phase 1 behavior (routing test only):**
```
/campaign/<alias>/<link-id>  →  302 /ig
/campaign/<alias>            →  400 "invalid redirect"
/campaign/                   →  400 "invalid redirect"
```

Path parsing:
```js
const parts = url.pathname.split("/").filter(Boolean);
// ["campaign", "spring-2026-youtube", "official"]
const alias = parts[1];
const link  = parts[2];
```
