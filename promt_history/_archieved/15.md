### PART 1 ✅ — Shared Retry Utility (`functions/_shared/retry.js` — YENİ)

```js
export async function retryWithBackoff(fn, options = {}) { ... }
// delays: [1000, 2000, 4000, 8000, 16000, 32000]  → toplam ≈63s
// fn() → { ok: boolean, ...fields }
// ok: true → erken çıkış; ok: false → retry; throw → ok:false + retry
```

Tasarım kararı:
- fn() her zaman bekler (`await sleep(delay[i])`) → ilk çağrı da 1s sonra yapılır.
- AE latency 52–57s ölçüldü → 32s son delay bu pencereyi kapatır.
- Tüm AE retry mantığı buraya taşındı; test-runner + manual-test birini import eder.

---

### PART 2 ✅ — Smoke Test Güncelleme (`test-runner.js`)

**Değiştirilen:** `retryAeQuery()` + `AE_RETRY_DELAYS` + `sleep()` kaldırıldı.

**Yeni Layer 1D + Layer 2 akışı:**
```js
import { retryWithBackoff } from "./retry.js";

const combined = await retryWithBackoff(async () => {
  const r = await queryRecentEvents(accountId, apiToken);
  if (!r.ok) return { ok: false, aeQueryOk: false, events: [], error: r.error };
  return { ok: r.events.length > 0, aeQueryOk: true, events: r.events };
});
// → analyticsOk = aeQueryOk && events.length > 0
// → consistencyProbe({ ok: aeQueryOk, events })  (ekstra sorgu yok)
```

Window: ~15s (eski 4-adım) → ~63s (6-adım). False negative riski ortadan kalktı.

### PART 4 ✅ — Manual Validation Stabilizasyonu (`manual-test.js` — komple güncellendi)

**Kaldırılan:** `RETRY_DELAYS`, `queryCounts()`, `waitForDelta()`

**Yeni akış:**
1. `testStartMs = Date.now()` → test_start kaydedildi
2. Click sequence ateşlendi (`/nb?test_run=1` ×2, `/nb/offer`, `/nb/vsl`)
3. `retryWithBackoff(async () => queryEventsSince(accountId, apiToken, testStartMs))`
