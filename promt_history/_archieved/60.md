# Prompt 60 — KV Slug Resolver

We now upgrade the /campaign router to resolve real destinations using KV.

Current state:

/campaign/:alias/:link

is routed through a catch‑all Cloudflare Pages Function:

functions/campaign/[[path]].js

The router currently redirects everything to `/ig` as a temporary stub.

This prompt replaces that stub with a deterministic KV lookup.

---

# Goal

Resolve redirects using the following lookup chain:

alias → campaign
campaign + link → destination URL

The router must stay deterministic and stateless.

---

# KV Namespace

Use the existing namespace binding:

LINKHUB_SLUGS

It is already defined in `wrangler.toml`.

---

# KV Data Model

Keys follow this structure:

alias:<alias>
→ returns campaign id

link:<campaign>:<link>
→ returns destination URL

Example KV entries:

alias:spring-2026-youtube
→ spring-2026

link:spring-2026:official
→ https://www.niluferormanli.com/spring-2026

link:spring-2026:newsletter
→ https://www.niluferormanli.com/spring-2026-lead

---

# Router Logic

Inside `functions/campaign/[[path]].js` implement:

1) Parse URL

Example request:

/campaign/spring-2026-youtube/official

alias = spring-2026-youtube
link  = official

2) Resolve campaign

KV key:

alias:<alias>

If not found → return 404

3) Resolve destination

KV key:

link:<campaign>:<link>

If not found → return 404

4) Redirect

Return 302 redirect to the resolved destination URL.

Use explicit headers instead of Response.redirect.

---

# Example Implementation

```javascript
export async function onRequest(context) {

  const url = new URL(context.request.url)

  const parts = url.pathname
    .split("/")
    .filter(Boolean)

  const alias = parts[1]
  const link  = parts[2]

  if (!alias || !link) {
    return new Response("invalid redirect", { status: 400 })
  }

  const kv = context.env.LINKHUB_SLUGS

  const campaign = await kv.get(`alias:${alias}`)

  if (!campaign) {
    return new Response("alias not found", { status: 404 })
  }

  const destination = await kv.get(`link:${campaign}:${link}`)

  if (!destination) {
    return new Response("link not found", { status: 404 })
  }

  return new Response(null, {
    status: 302,
    headers: {
      Location: destination
    }
  })
}
```
