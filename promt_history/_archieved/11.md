### Fix 3 ✅ — Numeric normalization (`functions/api/admin/analytics.js`)

AE bazen sayısal değerleri string olarak döndürüyor. `clicks` field'ı artık her zaman `Number` türünde:

```js
// Before:
const campaigns = campRes.status === "fulfilled" ? rows(campRes.value) : [];

// After:
const campaigns = campRes.status === "fulfilled"
  ? rows(campRes.value).map(r => ({ ...r, clicks: Number(r.clicks) }))
  : [];
```

`campaigns`, `aliases`, `slugs` normalize edildi. `recent` dokunulmadı (clicks field'ı yok).

Response shape değişmedi — `{ ok, campaigns, aliases, slugs, recent, duration_ms, generated_at }`.

### Fix 4 ✅ — Shared slug utility (`functions/_shared/slug-utils.js` — YENİ DOSYA)

**Root cause:** `deriveCampaign()` alias-router.js'de ve `buildCampaignFromSlug()` [[path]].js'de aynı mantığı, aynı 5 channel ile bağımsız olarak tekrarlıyordu.

**Yeni dosya:**

```js
// functions/_shared/slug-utils.js
export const KNOWN_CHANNELS = new Set(["igbio","igstory","yt","youtube","spotify"]);

export function deriveCampaignFromSlug(canonicalSlug) {
  const lastDash = canonicalSlug.lastIndexOf("-");
  if (lastDash < 1) return "";
  const suffix = canonicalSlug.slice(lastDash + 1);
  return KNOWN_CHANNELS.has(suffix) ? canonicalSlug.slice(0, lastDash) : "";
}
```

**alias-router.js:**
- `KNOWN_CHANNELS` Set + `deriveCampaign()` kaldırıldı
- `import { deriveCampaignFromSlug } from "./slug-utils.js"` eklendi
- 3 call site güncellendi (cache hit, modifier fallback, KV hit)

**[[path]].js:**
- `buildCampaignFromSlug()` fonksiyonu ve JSDoc'u kaldırıldı
- `import { deriveCampaignFromSlug } from "./_shared/slug-utils.js"` eklendi
- `CHANNEL_UTM` ve `buildDefaultUtms()` korundu — farklı işlev (utm_source + utm_medium mapping)
- Call site: `buildCampaignFromSlug(canonicalSlug)` → `deriveCampaignFromSlug(canonicalSlug)`

**Geriye dönük uyumluluk:** İki eski fonksiyonun mantığı özdeşti — aynı 5 channel, aynı lastDash algoritması. Hiçbir slug format değişmedi.
