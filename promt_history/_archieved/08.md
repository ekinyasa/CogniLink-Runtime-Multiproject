### Task 1 ✅ — slug.campaign fallback in `[[path]].js`

`functions/[[path]].js`

```js
// Before:
const campaign = buildCampaignFromSlug(canonicalSlug);

// After:
const campaign = (hubConfig?.campaign && String(hubConfig.campaign).trim())
  || buildCampaignFromSlug(canonicalSlug);
```

- Primary: uses `hubConfig.campaign` (explicit field stored in slug record / HUB_CONFIG)
- Fallback: `buildCampaignFromSlug()` heuristic for older records
- No additional KV reads — hubConfig is already loaded above
