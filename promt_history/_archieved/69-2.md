1) FIX: Experiments Create Button — JS ReferenceError
--------------------------------------------------

Creating...

1. Read form values

alias
campaign
variants[]
weights[]

const campaign = document.querySelector('#exp-campaign').value

(or equivalent selector used in the UI)

2. Build payload

{
  alias,
  campaign,
  variants,
  weights,
  strategy
}

3. Send request

POST /api/ab

4. On success:

button label → "Created"

Important:

The JS must **not reference undefined variables**.

The button must also re‑enable itself if the request fails.

3) FIX: Stopwatch Toggle
--------------------------------------------------

Current behavior:

Click timer → starts
Click timer again → does NOT pause

Expected behavior:

Timer display acts as a toggle.

Logic:

if running → pause
if paused → resume

Pseudo logic:

if (isRunning) {
  clearInterval(timer)
  isRunning = false
} else {
  startTimer()
  isRunning = true
}

Reset button must still:

stop timer
reset display to 00:00.0
