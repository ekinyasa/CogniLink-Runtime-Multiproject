#request

We now want to introduce an automated testing system for Campaign OS.

The purpose is to validate routing, telemetry emission, and analytics integrity after future changes.

This test system must NOT run inside the Cloudflare Worker runtime and must NOT affect production deployment.

It will run locally using Node.js.

Create a lightweight testing framework called:

Campaign OS Test Runner v1

------------------------------------------------
1️⃣ PROJECT STRUCTURE
------------------------------------------------

Create a new directory:

/tests

Inside it create the following files:

tests/
  run-tests.js
  router.test.js
  modifier.test.js
  analytics.test.js
  telemetry.test.js

These scripts must use Node.js native fetch (or node-fetch if required).

Do NOT introduce heavy dependencies or testing frameworks.

This is intentionally a lightweight test runner.

------------------------------------------------
2️⃣ CONFIGURATION
------------------------------------------------

run-tests.js should read configuration from environment variables:

CAMPAIGN_OS_BASE_URL
ADMIN_TOKEN

Example:

export CAMPAIGN_OS_BASE_URL="https://campaign-os.pages.dev"
export ADMIN_TOKEN="..."

------------------------------------------------
3️⃣ ROUTER TEST
------------------------------------------------

router.test.js should verify:

GET /nb

Expect:

status = 200
response contains HTML
no error page

Return:

PASS / FAIL


------------------------------------------------
4️⃣ MODIFIER ROUTING TEST
------------------------------------------------

modifier.test.js should test:

GET /nb/offer
GET /nb/vsl
GET /nb/test

Expect:

status = 200
hub page rendered
no 404

Return:

PASS / FAIL


------------------------------------------------
5️⃣ TELEMETRY TEST
------------------------------------------------

telemetry.test.js should:

trigger events:

GET /nb
GET /nb
GET /nb/offer
GET /nb/vsl

Then wait 2 seconds.

Return PASS.


------------------------------------------------
6️⃣ ANALYTICS TEST
------------------------------------------------

analytics.test.js should call:

GET /api/admin/analytics

Headers:

Authorization: Bearer <ADMIN_TOKEN>

Validate:

response.ok === true

campaigns array exists
aliases array exists
slugs array exists
recent array exists

recent.length > 0

clicks must be numbers.


------------------------------------------------
7️⃣ TEST RUNNER
------------------------------------------------

run-tests.js should execute:

router test
modifier test
telemetry test
analytics test

Output example:

Campaign OS Test Runner v1

✓ router test
✓ modifier routing
✓ telemetry emission
✓ analytics integrity

ALL TESTS PASS

If any test fails:

print clear FAIL message and exit with non-zero code.

------------------------------------------------
8️⃣ DO NOT MODIFY RUNTIME
------------------------------------------------

This test runner must NOT modify:

/functions
/workers
/runtime code

It must remain a separate developer tool.

------------------------------------------------
END OF REQUEST

## 12.md — Implementation Summary

5 yeni dosya oluşturuldu. `/functions` runtime'a dokunulmadı.

---

### Proje yapısı

```
tests/
  run-tests.js       ← ana runner, env okur, tüm suiteleri sırayla çalıştırır
  router.test.js     ← GET /nb → 200 + HTML
  modifier.test.js   ← GET /nb/offer|vsl|test → 200 + HTML
  telemetry.test.js  ← 4 trigger isteği → 2s bekle → PASS
  analytics.test.js  ← /api/admin/analytics integrity doğrulama
```

---

### Kullanım

```bash
export CAMPAIGN_OS_BASE_URL="https://campaign-os.pages.dev"
export ADMIN_TOKEN="your-token"
node tests/run-tests.js
```

Çıktı:

```
Campaign OS Test Runner v1
Base URL  : https://campaign-os.pages.dev
─────────────────────────────────────────────
✓  router test
✓  modifier routing
  (waiting 2s for AE ingestion…) done
✓  telemetry emission

─────────────────────────────────────────────

ALL TESTS PASS
```

### Test açıklamaları

| Dosya | Neyi test eder |
|-------|----------------|
| `router.test.js` | `GET /nb` → 200, HTML body içerir |
| `modifier.test.js` | `GET /nb/offer`, `/nb/vsl`, `/nb/test` → hepsi 200 + HTML |
| `telemetry.test.js` | 4 route isteği atar, 2s bekler, istekler 200 dönerse PASS |
| `analytics.test.js` | `/api/admin/analytics` → `ok=true`, 4 dizi var, `recent.length > 0`, `clicks` tipi Number |

---

### Teknik notlar

- **Node 18+ native fetch** — ek bağımlılık yok, `node-fetch` gerekmez
- **ESM modüller** — tüm dosyalar `export async function run(config)` arayüzüyle tutarlı
- **Sıralı çalışma** — telemetry önce event atar, analytics sonra bunları doğrular
- **analytics.test.js** — `recent.length === 0` durumunu açık mesajla FAIL yapar: telemetry testi önceden çalıştırılmalı
- **AE warnings** — `data.warnings` varsa console'a uyarı yazar, testi kesmez
- **Non-zero exit** — herhangi bir test FAIL → `process.exit(1)` → CI pipeline bozulur
