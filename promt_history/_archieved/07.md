### TASK 1+2 — compileRoutes fix + debug summary

**Root cause of "only 2 aliases read" (partial ALIAS_REGISTRY listing):**

`listAllKeys()` was passing `cursor: undefined` explicitly in the KV `list()` options object on the first call. Some KV implementations treat `{ cursor: undefined }` differently from omitting the key entirely — potentially skipping the first page or misinterpreting the pagination state.

**Fix in `functions/_shared/route-compiler.js`:**

```js
// Before (potentially broken first-page cursor):
const page = await ns.list({ prefix, cursor, limit: 1000 });

// After (cursor only included when paginating):
const listOpts = { prefix, limit: 1000 };
if (cursor !== undefined) listOpts.cursor = cursor;
const page = await ns.list(listOpts);
```

Applied to both `listAllKeys()` (ALIAS_REGISTRY reads) and `buildCampaignSlugMap()` (LINKHUB_SLUGS reads).

**Expected compile stats after fix:**

### TASK 7 — utm_campaign auto-default

**Problem:** Routes resolved via `[[path]].js` (alias → canonical slug) did not pass `campaign` to `renderHub()`. Client-side JS received `CAMPAIGN = ""`, so `utm_campaign` was never set on hub links. Direct `/c/[slug]` URLs were already correct (they read `campaignData.campaign`).

**Fix in `functions/[[path]].js`:**

New helper `buildCampaignFromSlug()`:

```js
function buildCampaignFromSlug(canonicalSlug) {
  const lastDash      = canonicalSlug.lastIndexOf("-");
  if (lastDash < 1) return "";
  const channelSuffix = canonicalSlug.slice(lastDash + 1);
  if (!(channelSuffix in CHANNEL_UTM)) return "";   // unrecognised channel → ""
  return canonicalSlug.slice(0, lastDash);
}
```

Examples:
- `new-beta-igbio` → channel `igbio` ∈ CHANNEL_UTM → campaign `new-beta` ✓
- `atlas-release-igstory` → channel `igstory` ∈ CHANNEL_UTM → campaign `atlas-release` ✓
- `unknown-slug-xyz` → channel `xyz` ∉ CHANNEL_UTM → `""` (utm_campaign omitted) ✓

`renderHub()` call updated:

```js
const campaign = buildCampaignFromSlug(canonicalSlug);

renderHub({
  contextType: "campaign",
  contextId:   canonicalSlug,
  campaign,               // ← NEW: drives utm_campaign on all links
  defaultUtms,
  links,
  ...
});
```

**Result — link now generated correctly:**

```
Before: https://niluferormanli.com/?utm_source=instagram&utm_medium=bio&utm_content=primary_official
After:  https://niluferormanli.com/?utm_source=instagram&utm_medium=bio&utm_campaign=new-beta&utm_content=primary_official
```

No extra KV reads. Campaign name is derived from canonical slug by convention.
