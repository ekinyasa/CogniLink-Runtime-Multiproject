### Fix 1 ✅ — Analytics tab wiring

**Root cause:** Admin renderer HTML ve JS 08.md'de doğru eklenmişti. Asıl sorun: `loadAnalytics()` fonksiyonu `data.byCampaign / data.byAlias / data.bySlug` key'lerini okurken analytics API `campaigns / aliases / slugs` döndürüyordu — key mismatch. Tab görünse bile tablolar boş kalıyordu.

**Değişen:** `functions/_shared/admin-renderer.js`

```js
// Before:
renderAnalyticsTable("by-campaign", data.byCampaign, "campaign", "clicks");
renderAnalyticsTable("by-alias",    data.byAlias,    "alias",    "clicks");
renderAnalyticsTable("by-slug",     data.bySlug,     "slug",     "clicks");

// After:
renderAnalyticsTable("by-campaign", data.campaigns, "campaign", "clicks");
renderAnalyticsTable("by-alias",    data.aliases,   "alias",    "clicks");
renderAnalyticsTable("by-slug",     data.slugs,     "slug",     "clicks");
```

Tab yapısı zaten doğruydu:
- `Analytics` ilk tab, default `active` ✓
- `showPanel()` → `loadAnalytics()` çağrısı ✓
- `tab-analytics` panel ID ✓

### Fix 2 ✅ — Analytics API 404

**Root cause:** `onRequestGet` export — Cloudflare Pages Functions route matching bazı durumlarda method-specific exports'u tanımıyor. `onRequest` (tüm metodlar) daha güvenli ve Pages Functions docs'un önerdiği format.

**Değişen:** `functions/api/admin/analytics.js`

```js
// Before:
export async function onRequestGet(context) { ... }

// After:
export async function onRequest(context) {
  if (request.method !== "GET") {
    return 405 Method Not Allowed;
  }
  ...
}
```

**Response shape da düzeltildi** — admin UI ile uyumlu:

```json
{
  "ok": true,
  "campaigns": [{ "campaign": "new-beta", "clicks": 42 }],
  "aliases":   [{ "alias": "nb", "clicks": 42 }],
  "slugs":     [{ "slug": "new-beta-igbio", "clicks": 42 }],
  "recent":    [{ "ts": "...", "alias": "nb", "slug": "...", "campaign": "...", "modifier": "" }]
}
```

Error responses de (`not_configured`, `query_failed`) artık boş array'lerle dönüyor — admin UI'nın parse etmesi için.

### Fix 3 ✅ — Modifier routing 404

**Root cause:** `/nb/offer` → `buildRouteKey("nb","offer")` = `"nb@offer"` → ROUTE_TABLE'da `route:nb@offer` yok (sadece `route:nb` var) → KV miss → 404.

**Fix:** Step 6'ya modifier fallback eklendi — ROUTE_TABLE yapısı değişmedi, format değişmedi.

**Değişen:** `functions/_shared/alias-router.js`

```
Step 6 (KV miss logic):

  if (kvSlug === null) {
    if (modifier !== null) {                         // /nb/offer
      baseSlug = ROUTE_TABLE.get("route:nb")         // 2nd read (O(1))
      if (found) {
        routeCacheSet("nb@offer", baseSlug)          // cache modifier key
        emit route_resolved + alias_click
        return { ok: true, canonicalSlug: baseSlug }
      }
    }
    // true 404 (alias not found)
  }
```

**Routing logic sonucu:**
```
/nb        → route:nb        → hit (1 read)     → hub renders ✓
/nb/offer  → route:nb@offer  → miss             → fallback
           → route:nb        → hit (2 reads)    → hub renders ✓
/nb/vsl    → route:nb@vsl    → miss             → fallback
           → route:nb        → hit (2 reads)    → hub renders ✓
```

İlk requestten sonra modifier-qualified key Workers Cache'e yazılır (`routeCacheSet`) → sonraki `/nb/offer` requestleri 1 cache read ile çözülür.

**ROUTE_TABLE değişmedi** — `compileRoutes()` dokunulmadı — O(1) korundu.
