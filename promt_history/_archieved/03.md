### Request 1 — Runtime re-architecture (ROUTE_TABLE + Workers Cache)

**ROUTE_TABLE KV namespace** introduced as the sole runtime read target.

Compiled flat index schema:
```
route:<alias>            → canonical_slug   (default channel)
route:<alias>@<modifier> → canonical_slug   (modifier route)
```

**ALIAS_REGISTRY and CAMPAIGN_REGISTRY** are now ops-only truth sources. They are NEVER read during normal public routing — only by `compileRoutes()`.

**Workers Cache layer** (`route-cache.js`) added in front of ROUTE_TABLE:

| Path | KV reads |
|---|---|
| warm (Workers Cache hit) | **0** |
| cold (cache miss) | **1** (ROUTE_TABLE) |
| hub config (cold) | **+1** (HUB_CONFIG) |
| global design config (cold) | **+1** (LINKHUB_CONFIG) |

Cache key URL: `https://route-cache.linkhub.internal/<encodeURIComponent(routeKey)>`
TTL: `ROUTE_CACHE_TTL` env var in seconds (default 60).

**Legacy hub fallback** gated behind `ENABLE_LEGACY_HUB_FALLBACK=true` (default OFF). If OFF, `LINKHUB_SLUGS` is never read.

### Request 2 — Production hardening

**`validators.js`** — three deterministic validators, no auto-correction:
- `validateAlias(s)` — `[a-z0-9-]`, max 48 chars
- `validateModifier(s)` — `[a-z0-9-]`, max 32 chars
- `validateCanonicalSlug(s)` — `[a-z0-9-]` with at least one dash, max 200 chars

**`route-cache.js`** — Workers Cache API wrappers:
- `routeCacheGet(routeKey)` → string | null
- `routeCacheSet(routeKey, slug, env)` → void (fire-and-forget)
- `invalidateRouteCache(routeKey)` → void
- `invalidateRoutes(routeKeys[])` → void (parallel)
- Graceful degradation in local dev (caches.default unavailable → no-op)

**`route-compiler.js`** — `compileRoutes(env, opts)` ops utility:
- Reads ALIAS_REGISTRY (paginated list) + CAMPAIGN_REGISTRY
- Validates: alias → campaign_id → campaign record → channels → modifier_map targets → canonical_slug format
- Duplicate route key detection → hard error
- Atomic write: if any error exists, ROUTE_TABLE is not written (fail-safe)
- Invalidates Workers Cache for all compiled keys after successful write
- Supports `dryRun: true` for validation-only runs
- Returns `{ ok, written, compiled, errors, skipped }`

**`alias-router.js`** (rewritten) — 8-step pipeline:
```
1. parsePath         → normalize, strip trailing /, split, path traversal guard
2. validateAlias     → [a-z0-9-] max 48
3. validateModifier  → [a-z0-9-] max 32  (if present)
4. Workers Cache     → routeCacheGet(routeKey)
5. ROUTE_TABLE KV    → ROUTE_TABLE.get("route:<routeKey>")
6. 404 on miss       → no fallback
7. validateCanonical → format guard (also guards cache-poisoning)
8. return { canonicalSlug, cacheHit }
```

`loadHubConfig()` moved here from catch-all (cleaner separation).

**`[[path]].js`** (rewritten) — emits structured log per request:
```json
{ "routeKey": "album@ig", "canonical_slug": "album-launch-igbio",
  "cache": "hit", "kvRead": false, "latency_ms": 2, "request_id": "..." }
```
`routeKey` (containing alias) is logged for ops debugging but NOT forwarded to analytics. Only `canonical_slug` flows into `renderHub()` and analytics.
