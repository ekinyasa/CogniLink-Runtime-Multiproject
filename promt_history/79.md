## Task 1 — Missing conversion trigger (FIXED)

**File:** `functions/t.js`

**Change 1 — import:**
```js
import { maybeRebalance } from "./_shared/bandit-rebalance.js";
```

**Change 2 — trigger inside `if (e === "conversion")` block:**
```js
if (e === "conversion") {
  context.waitUntil(incrementExpCounter(env, exp, v, "conversion"));
  // Every conversion is a reliable signal — wire it directly to maybeRebalance.
  // exp = experiment identifier (maps to ab_config:<exp> in CAMPAIGN_REGISTRY).
  // maybeRebalance is guarded internally (cooldown, strategy, eligibility gates).
  context.waitUntil(maybeRebalance(env, exp, "conversion"));
}
```

**Variable note:** `exp` (not `alias`) is the experiment identifier in `t.js`. `alias` in `t.js` is the entry link slug used only for breakdown counters — passing it to `maybeRebalance` would look up the wrong `ab_config` key. `exp` maps directly to `ab_config:<exp>` in CAMPAIGN_REGISTRY.
