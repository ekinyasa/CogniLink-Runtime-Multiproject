## Log points added (prefix: `[BANDIT:DBG]`)

| Point | Tag | What it shows |
|---|---|---|
| Entry | `enter` | alias, trigger |
| Guard 1 miss | `SKIP in-memory-cooldown` | lastMemo, now, remainingMs |
| Guard 1 pass | `PASS in-memory-cooldown` | alias, lastMemo (null = first run) |
| KV read error | `SKIP kv-read-error` | error message |
| KV miss | `SKIP no-config` | alias |
| KV hit | `kv-config` | strategy, state, last_rebalance, winner_at_last_rebalance, weights |
| Guard 2: strategy | `SKIP strategy-fixed` | alias |
| Guard 2: state | `SKIP state-not-running` | alias, state |
| Guard 2 pass | `PASS strategy+state` | alias, strategy, state |
| Perf error | `SKIP perf-read-error` | error message |
| Perf snapshot | `perf-snapshot` | per variant: slug, exposures, conversions, cvr, eligible (true/false) |
| No winner: eligibility | `SKIP no-winner:eligibility` | eligibleCount, per variant expOk / convOk |
| No winner: delta | `SKIP no-winner:delta-too-small` | leader, runner, deltaAbs, deltaRel, needAbs, needRel |
| Winner detected | `PASS winner-detected` | winner slug |
| Guard 3: persisted cooldown | `SKIP persisted-cooldown:same-winner` | winner, last_rebalance, remainingMs |
| Guard 3: winner changed | `PASS persisted-cooldown:winner-changed` | prev, next |
| Guard 5: no-op | `SKIP no-op-weights` | oldWeights, newWeights |
| KV write success | `DONE kv-written` | alias, newWeights |
